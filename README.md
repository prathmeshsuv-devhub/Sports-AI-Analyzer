# 🏆 Sports AI Analyzer
## 🌐 Live Demo

👉 [Open Sports AI Analyzer](https://sports-ai-analyzer-krniaa4moewwzxjssgwv5f.streamlit.app)
An interactive sports player performance analytics dashboard built using Python and Streamlit.

## 📌 Project Overview

Sports AI Analyzer helps analyze and compare sports players using performance data.

The application provides player performance scores, interactive charts, player-to-player comparison, downloadable PDF reports, and AI-style performance analysis.

## ✨ Features

- 📊 CSV / Excel sports data upload
- 🏆 Player performance scoring
- 📌 Dashboard KPI cards
- 📈 Interactive performance charts
- 🆚 Player comparison
- 👤 Individual player performance analysis
- 📄 Downloadable PDF performance reports
- 🤖 Free AI-style player analysis
- 🌐 Streamlit Cloud deployment

## 📊 Performance Metrics

The project analyzes:

- Runs
- Goals
- Assists
- Pass Accuracy
- Fitness
- Overall Performance Score

## 🆚 Player Comparison

Users can select two players and compare:

- Runs
- Goals
- Assists
- Pass Accuracy
- Fitness
- Performance Score

The application also identifies the better overall performer based on the calculated performance score.

## 📄 Performance Reports

The application can generate a downloadable PDF report containing:

- Player information
- Performance metrics
- Strengths
- Areas for improvement
- Performance rating
- Recommendations

## 🤖 AI Player Analysis

The application provides automated player analysis based on the uploaded performance data.

The analysis includes:

- Overall rating
- Strengths
- Areas for improvement
- Performance recommendation

This version uses local data-driven analysis and does not require paid AI API credits.
